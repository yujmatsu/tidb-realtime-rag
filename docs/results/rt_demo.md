## ⚡ イベント発生: 商品5が完売 → 在庫0に更新（ライブのみ反映、同期はまだ）

👤 ユーザー: 商品5は在庫ありますか？
  ❌ Before(同期型RAG・古いスナップショット): はい、商品5は現在12個在庫があります。

     ↑参照した文脈: 商品5 の現在在庫: 0 個
